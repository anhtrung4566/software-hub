3 Lựa Chọn AI & Câu Hỏi Thường Gặp (FAQ)

  • Ollama Local (Mặc định — Miễn phí, không cần API Key): Chạy trực tiếp tại http://127.0.0.1:11434. Tải tại ollama.com/download, tải model tiếng Việt ollama pull qwen2.5:3b (1.9GB) hoặc qwen2.5:7b (4.7GB).
  • Google Gemini API (Tùy chọn bổ sung): Lấy khóa chính thức tại aistudio.google.com/app/apikey (không bắt buộc nếu đã dùng Ollama).
  • OpenAI API (Tùy chọn trả phí theo token): Lấy khóa chính thức tại platform.openai.com/api-keys (lưu ý: gói ChatGPT trên web không bao gồm hạn mức OpenAI API; VBTM Pro không bao giờ tự chuyển sang OpenAI trả phí khi chưa được phép).
  • FAQ — VBTM Pro có tự ý chỉnh thể thức khi mở file không? Không. Mở, nhập, dán hoặc lưu tài liệu giữ nguyên 100% nguyên trạng. Bạn chủ động bấm KT 05-HD / Chuẩn hóa 05-HD hoặc KT NĐ 30 / Chuẩn hóa NĐ 30 để xem trước, xác nhận áp dụng và có thể Hoàn tác bất cứ lúc nào.
